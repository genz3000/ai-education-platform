# AI 教育知識庫系統 (genz3000-ai-education)

> 校本 AI 教學操作系統 (School AI OS) — 香港學校版

## 定位

不是工具，而是**教學基礎設施**。

基於香港教育局「智啟學教」政策，建立 AI + 校本知識庫 + 學習數據融合的教學系統。

## 系統架構

```
┌─────────────────────────────────────────────────────────────┐
│                        AI 服務層                             │
│  LLM (GPT-4/Claude) + RAG + Prompt Engine + Agent 調度      │
├─────────────────────────────────────────────────────────────┤
│                       知識庫層                               │
│  教材向量化 + 題庫系統 + 課綱映射 + 知識圖譜                 │
├─────────────────────────────────────────────────────────────┤
│                      應用服務層                              │
│  AI問答 │ AI出題 │ AI批改 │ AI教案 │ 學習路徑                │
├─────────────────────────────────────────────────────────────┤
│                      數據分析層                              │
│  學習行為 + 成績分析 + 學習預測 + 報告生成                   │
├─────────────────────────────────────────────────────────────┤
│                       平台層                                │
│  用戶管理 + 權限系統 + LMS API 接口 + 日誌監控               │
├─────────────────────────────────────────────────────────────┤
│                      安全合規層                              │
│  數據加密 + 角色權限 + 審計記錄 + 香港私隱條例合規           │
└─────────────────────────────────────────────────────────────┘
```

## 核心功能模組

| 模組 | 功能 |
|------|------|
| **AI 教育知識庫** | 教材上傳、OCR、向量化、知識圖譜、課綱對應 |
| **AI 智能問答** | RAG 問答、多輪對話、教師/學生模式、教學解釋 |
| **AI 評估與出題** | 按 DSE/TSA 生成題目、難度控制、AI 批改、主觀題語意評分 |
| **學習歷程與分析** | 行為追蹤、強弱項分析、學習風險預測、報告系統 |
| **教師支援系統** | AI 教案生成、教學分析、班級管理、教材共編 |

## 技術棧

### 前端
- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **UI**: TailwindCSS + shadcn/ui
- **State**: Zustand
- **i18n**: next-intl (繁體中文支援)

### 後端
- **Framework**: FastAPI (Python)
- **Database**: PostgreSQL + pgvector
- **Cache**: Redis
- **LLM**: OpenAI GPT-4 / Anthropic Claude

### 基礎設施
- **Container**: Docker + Docker Compose
- **Orchestration**: Kubernetes (k8s/)
- **Package Manager**: Helm (helm/)

## 快速開始

### 開發環境

```bash
# 前端
cd frontend && npm install && npm run dev

# 後端
cd backend && pip install -r requirements.txt && uvicorn src.main:app --reload

# Docker Compose (完整環境)
docker-compose up -d
```

### 學校需提供資料

1. **教學資料**: 教材、教案、題庫、課綱 → 知識庫 + AI訓練
2. **學生數據**: 成績、行為、查詢紀錄 → 個性化學習
3. **系統資料**: LMS API、班表 → 系統整合
